## The problem

Every three weeks, regression testing meant half a day of manual work, more than four hours each time. Because the same work came back every cycle, it was a clear candidate for automation. The client projects stay anonymous here.

## What I built

I automated 60+ test cases with Playwright and organized them using page objects. That took regression testing from over four hours to roughly two.

I currently run the tests by hand. The next step I'm hoping for is to bring them into a CI/CD pipeline.

## The hard decision

The biggest call was choosing the right automation framework for the job. I considered Selenium and WebdriverIO before settling on Playwright. I needed something fast and easy to set up, and that decided it.

## What I'd change

I wouldn't write the page objects by hand again. I'd have an AI agent do that work, so I could focus on the automation instructions.
